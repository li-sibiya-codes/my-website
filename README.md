# my-website

A personal portfolio website built with HTML, CSS and JavaScript to showcase my academic background, technical skills, projects and interests.

## Overview

This project is a personal portfolio website that I have been developing as a practical way to learn and experiment with front-end web development.

The website has grown from a simple single-page portfolio into a multi-page site with custom styling, background imagery, a profile picture, interactive project cards and JavaScript-powered features.

The design combines a professional portfolio structure with a more personal and creative visual style.

## Features

* Multi-page website with navigation between pages
* About section with personal and academic information
* Education and technical skills sections
* Projects section showcasing programming and development work
* Contact section
* Custom profile picture
* Background imagery and decorative visual elements
* Interactive project cards with hover effects
* Project card tilt effect on hover
* Navigation scroll effects
* Scroll reveal animations
* Dynamic greeting based on the current time of day
* Consistent visual styling across pages
* Custom typography, spacing and layout

## Technologies Used

* HTML
* CSS
* JavaScript

## JavaScript Features

The website uses JavaScript to add small interactive and dynamic features, including:

* Displaying a dynamic greeting based on the current hour
* Adding interaction to project cards
* Creating a tilt effect when hovering over project cards
* Navigation and scroll-based effects
* Revealing content as the user scrolls through the page

The JavaScript is primarily used to enhance the existing HTML and CSS rather than act as the main component of the website.

## Project Goals

The project was created to improve my understanding of front-end web development while building something that I can use as a personal portfolio.

Through developing the website, I have been strengthening my understanding of:

* HTML structure and semantic organisation
* CSS styling and layout
* JavaScript and DOM manipulation
* User interaction and basic animations
* Page organisation and navigation
* Visual design and typography
* Presenting technical projects in a portfolio format
