# my-website
Using html &amp; css to create and style a website with  my personal information

Overview

This project is a single page personal portfolio website developed using HTML and CSS. The purpose of the website is to present my academic background, technical skills and projects in a clear and professional format. The design focuses on clean structure, readability and consistent visual styling suitable for formal use.

Features
	•	Single page layout for simple navigation
	•	Structured sections for About, Skills, Projects, Education and Contact
	•	Clean and accessible HTML structure
	•	Consistent styling using CSS

Technologies Used
	•	HTML
	•	CSS

Project Goals

The project was created to improve my understanding of front end development and content organization for professional presentation. Through this process I strengthened my skills in layout planning, web structure and writing formal project documentation.

Future Improvements
	•	Expand the website into a multi page structure
	•	Add interactive elements using JavaScript once I learn it
	•	Improve responsiveness for different screen sizes
	•	Refine visual layout and spacing as the project grows

Status

This project is an ongoing learning project and will be updated as I continue developing my skills.
